# Snake-Game-Python
# لعبة الثعبان الكلاسيكية (Nokia Snake Game) 🐍

مشروع إعادة بناء لعبة الثعبان المشهورة بلغة بايثون باستخدام مفاهيم البرمجة كائنية التوجه (OOP).

## مميزات اللعبة والهيكلية:
- **OOP Structure:** تقسيم عناصر اللعبة (الثعبان، الطعام، لوحة النتيجة) إلى Classes مستقلة.
- **Game Logic:** التحكم في الحركة، كشف التصادم (Collision Detection)، وزيادة الطول والنقاط.
- **Clean Code:** كود منظم ومقسم على عدة ملفات لسهولة الصيانة والتطوير.

## كيفية التشغيل:
1. قم بتحميل الملفات.
2. شغل الملف الرئيسي: `python main.py`
